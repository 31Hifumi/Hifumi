# 开发需求文档

## 一、技术决策（已确认）

### 1.1 Frontmatter 字段规范

统一使用 Firefly 主题原生字段名：

```yaml
---
title: 文章标题
published: YYYY-MM-DD
category: 分类名称
tags: [标签1, 标签2]
image: 封面图路径
description: 文章摘要
draft: false
---
```

| Firefly 原生字段 | 说明 |
|---|---|
| `title` | 文章标题 |
| `published` | 发布日期 |
| `category` | 分类（单数，一篇一个分类） |
| `tags` | 标签数组 |
| `image` | 封面图（支持本地路径或 `"api"` 随机封面） |
| `description` | 文章摘要描述 |
| `draft` | `true`=草稿不发布，`false`=发布 |

### 1.2 特效策略

- **当前阶段**：仅使用 Firefly 内置特效（樱花等），通过 `effectsConfig.ts` 配置
- **预留扩展**：架构上保留自定义特效接入点，不写死，后续可随时添加粒子/点击礼花等动效
- **不做**：移动端动效自动降级（已从需求中移除）

### 1.3 背景系统

使用 Firefly 原生壁纸系统（`backgroundWallpaper.ts`），支持：
- 横幅壁纸 / 全屏壁纸 / 全屏透明壁纸 / 纯色背景
- 单篇文章独立设置背景

### 1.4 内容分类体系

预设三大分类，一篇一个分类，不设子分类：

| 分类 | 用途 |
|---|---|
| `日常随笔` | 生活碎碎念、心情记录、日常琐事 |
| `图集分享` | 实拍照片、风景作品、日常摄影 |
| `读书笔记` | 书籍摘抄、读后感、学习复盘 |

后续可自由新增分类，无数量限制。

### 1.5 图片存储路径

所有配图统一存放 `src/assets/images/`，使用相对路径引用：

```
src/assets/images/
├── covers/     # 文章封面图
├── posts/      # 文章内容配图（按文章分文件夹）
└── site/       # 站点通用图片（Logo、favicon、背景图等）
```

- 通过 Astro 原生图片优化（压缩、格式转换、尺寸适配）
- 统一相对路径，不依赖外链图床
- 纳入 Git 版本管理

### 1.6 部署方案

- **托管平台**：Cloudflare Pages（免费、国内连通性相对较好）
- **构建命令**：`pnpm build`
- **输出目录**：`dist/`
- **自动部署**：Git push → Cloudflare Pages 自动构建发布

### 1.7 Git 版本管理

- **初始化时机**：项目骨架搭建完成后 `git init`
- **仓库内容**：全文稿件 + 图片素材 + 配置源码
- **本地 + 远程双备份**

### 1.8 视觉风格

**日系清新 + 粉蓝暖色调**：

| 元素 | 方案 |
|---|---|
| 主色调 | 樱花粉，色相 340-345 |
| 强调色 | 天空蓝（链接常态、暗色模式点缀） |
| 背景 | 日系动漫插画壁纸 + 磨砂玻璃半透明遮罩 |
| 暗色模式 | 深蓝底 + 低饱和紫粉文字 |
| 装饰 | 看板娘（Live2D/Spine 动漫角色）、樱花飘落特效 |
| 字体 | 默认系统字体，后期可加入日系字体 |

**配色参考**：

| 色值 | 用途 |
|---|---|
| `#F4A7B9` | 樱花粉主色 |
| `#7EC8E3` | 天空蓝强调 |
| `#FFF5F5` | 暖色背景底调 |

### 1.9 关于页

极简路线，不暴露个人信息：

- 一句话博客说明："记录日常、摄影与阅读的个人空间"
- 建站时间（YYYY-MM-DD）
- 可选匿名联系方式（邮箱 / 社交链接，后期补充）
- 不暴露真实姓名、工作、定位

### 1.10 robots.txt

```txt
User-agent: *
Disallow: /
```

全站禁止主流搜索引擎收录，零成本实现基本隐私防护。
